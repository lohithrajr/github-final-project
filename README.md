# Simple Interest Calculator

A simple, user-friendly script/application that calculates simple interest based on principal amount, annual interest rate, and time period in years.

## Description

This project provides a simple tool to calculate the interest earned or owed over a given period. It uses the standard simple interest formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal Amount
- **R** = Annual Interest Rate (in percentage)
- **T** = Time Period (in years)

## Features

- Quick and accurate simple interest calculations.
- Accepts user inputs for principal, rate of interest, and duration.
- Displays the total interest amount and final total balance.
